# 教学内容维护

默认库包含 **64 个教学条目**，按 NFL FLAG 2024 中英对照学习译本的顺序排列。每个阵型后保留对应的 PLAY 1、2、3。全部条目均可在[在线应用](https://titanxxh.github.io/flagventures/)或本地网页中使用，不依赖 PDF 或原页图片。

「进攻阵型与战术」使用 10 个可折叠的阵型组，每组包含阵型站位和战术 1、2、3。分组只增加目录层级，不改变条目数量或顺序。

| 内容 | 数量 |
| --- | ---: |
| 基础路线 | 10 |
| 静态阵型 | 10 |
| 进攻战术 | 30 |
| 跑球战术 | 9 |
| 防守方案 | 5 |

## 文件组织

- [lessons/](lessons/)：每个条目一份 YAML。
- [catalog.yaml](catalog.yaml)：章节、显示顺序与可选分组。
- `default.flagbook.json`：打包时生成的完整内容包，不纳入版本控制。

公开仓库与默认内容包不包含原页图片。来源名称、页码和教学说明保留在各条 YAML 中；图片不是构建或运行的前置条件。

## 新增或修改

1. 修改现有 YAML，或复制 [新增模板](../content-format/templates/new-play.yaml)。
2. 新条目使用唯一 `id`，并在 `catalog.yaml` 对应章节中加入文件路径和编号。
3. 在项目根目录运行 `npm test` 检查数据，再运行 `npm run build` 更新主网页。

需要分组时，在章节的 `groups` 中引用已有条目 ID；原有 `entries` 仍完整保留。打包后，分组会随章节写入内容包。分组不依赖 PDF，也不会按标题或页码自动推断；新增战术可以不分组。字段与示例见[战术文本格式](../content-format/README.md)。

测试和构建都会自动重新打包。只需生成内容包时，可以运行 `node tools/pack-content.mjs`。普通使用者也可以直接在网页里导入 YAML，并选择「保存完整战术包」，无需修改默认库或重新构建。

字段、路线、时序、分支和防守职责的写法见 [战术文本格式](../content-format/README.md)。自编内容不需要 PDF 来源或图片。

## 资料与教学表达

默认路线、站位与职责来自 NFL FLAG 2024 中英对照学习译本；30 套进攻战术的配合讲解、部分术语和启动关系补充参考 [NFL FLAG 官方介绍及视频](https://nflflag.com/coaches/flag-football-rules/5-on-5-flag-football-playbook)。中文为非官方学习译文及教学编写。各条目的 `source.references` 保留可核对的网页或视频出处；`teaching` 写全队讲解，`player.coaching` 写个人配合与时机。全部资料已保存在独立文本中，运行时不读取原始 PDF、原页图片或外部网页。格式仍支持为自行维护的内容包添加可选参考图片，详见[文本格式](../content-format/README.md)。

坐标保留原页观看方向与相对站位：进攻朝上，防守图对照的进攻方向朝下。坐标是绘图单位，不代表实际码数。球员字母确定身份，颜色只作辅助。

术语依据由 `label.basis` 区分：来源明确命名、路线形态对照、按图描述、作者编写或资料未说明。复杂组合路线使用实际方向描述，不强套一个英文名称。

原 PDF 没有规定跨球员的固定起跑先后。补充的官网与视频对部分进攻战术明确说明先后、等待或条件释放；相关条目区分这些关系，具体动画秒数仍为教学安排。没有明确先后依据的路线保留共同起步的演示节奏；时长不表示相同跑速或真实交接顺序。解说逐人介绍路线也不等于比赛逐人出发。STOP AND GO 的停顿动作有资料依据，具体停 1 秒是教学安排。

“其他人没有空位才释放接应”使用 `choice` 的两种互斥情形：家长先选，再播放；不把条件变成必然延迟启动。未触发分支保留起点并明确说明后续动作未知，不代表比赛中必须全程站住。所有分支、说明和来源都随战术包保存。新增讲解字段可省略，旧版自编条目无需补齐才能导入。

基础 OPTION 保留原图连续路径，不补写选择条件。HB OPTION 的 `PUMP FAKE + RUN`、QB OPTION 的 `RUN/PASS OPTION` 保留在说明中，不生成球权或交接动画。

防守区域与职责线采用 `zones` / `assignments`，不驱动动态追逐。没有画出路线的球员标为 `unspecified`，表示后续动作未知，不等于比赛中必须站住。
