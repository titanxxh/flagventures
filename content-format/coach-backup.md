# 完整编辑备份 v2

网页画板唯一的导入／导出格式为 JSON：`format: "flagventures.backup"`、`version: 2`。它与供内置手册维护的 v1 YAML 分开，不依赖 PDF，不提供旧格式用户导入或兼容演示导出。

[结构定义](coach-backup.schema.json)是应用实际使用的 JSON Schema；结构可读不等于战术可保存教学版。未完成草稿可以保留缺名称、空路线、失效绑定及待核对说明；已保存版本还要通过几何、时序、球权、五人和内容最低要求。

## 记录层次

| 字段 | 内容 |
| --- | --- |
| `records[]` | 单套／整库战术记录；导入不清空其他记录 |
| `id`、`revision`、`updatedAt` | 独立身份、写入修订、更新时间；名称不作为覆盖身份 |
| `draft` | 当前编辑草稿 |
| `saved` | 最近一次手动保存的教学版，可为 `null` |
| `history[]` | 最近 10 个手动版本，含版本 ID、时间和完整 `play` |

在线／固定来源本地服务用 IndexedDB 原子事务；提交成功才显示已保留。两页按修订检查冲突。双击单 HTML 用会话内存，必须导出备份带走内容。不同浏览器、设备、网址／端口不自动共享。

导入完全相同内容跳过，同身份不同内容逐条选替换／复制／跳过。替换经确认直接替换该记录及草稿／历史；复制生成独立战术身份并补唯一名称。其他记录保留。名称按首尾／连续空格和英文大小写规范化检重。结构或保存版损坏、未知版本拒绝，不重置当前库。单文件导入上限 25 MB。

## 编辑内容

`draft`、`saved` 和历史中的 `play` 均使用 `format: "flagventures.play"`、`version: 2`。

| 字段 | 含义 |
| --- | --- |
| `type` | `offense` / `run` / `route` / `formation` / `defense` |
| `title.zh/en` | 可只填一种语言；正式保存名称不能为空或与另一战术重名 |
| `field` | 30 × 70 码球场、开球线、两端区与方向 |
| `players[]` | 五人，稳定 `id`、显示名称、`at`、术语和基础 `motion` |
| `scenarios[]` | 互斥演示方案、`mode`（跑位或球路）、`choices`、按球员 ID 的 `overrides`、独立 `events` |
| `defaultScenario` | 明确默认方案，不因删除自动选择另一项 |
| `initialOwner` | 初始持球人；仅跑位模式不生成球 |
| `sharedEvents[]` | 显式共享的多步球动作前序，各方案独立链接在后面 |
| `bookmarks[]` | 稳定停点身份、标题、绑定、可选方案作用域与独立 `view` 图层 |
| `zones[]` / `assignments[]` / `targets[]` | 椭圆／矩形／多边形、静态覆盖／盯人／冲传职责、命名参照标记 |
| `origin` | 自编或改编；改编保留来源、原始标题、参考身份及原始数据只读对照 |
| `explanation` | 当前对象的中英说明与 `confirmed` / `review` 状态；没有独立私有备注 |

播放器从编辑关系计算秒数和画面，不把计算结果当另一种导出文件。动作、引用和说明依赖稳定 ID，不能依赖数组下标。未说明、明确原位和停顿有不同含义。

## 时序关系

路线的 `motion.start` 可为延迟或队友动作依赖：

```json
{"type":"delay","seconds":0}
```

```json
{"type":"action","player":"X","action":"action-id","phase":"end","offset":0.5}
```

路线动作有独立 `id`，支持 `line`、`quadratic`、`cubic`、`pause`；`seconds` 为示意耗时，`timing: "auto"` 随实际长度重新计算，`fixed` 保留人工耗时。新画动作沿跑动方向；旧 `facePlayer` 保留，受改动影响时明确核对或移除。

球动作有 `start`、可选 `end`，二者可为固定时间或路线动作绑定。支持 `snap`、`pass`、`handoff`、`fake-handoff`、`pump-fake`。出手／接球位置取两个时刻的球员位置；假动作不转移持球人，交递双方须会合。0.5 码会合容差是本应用教学校验，不是比赛规则。

停点 `binding` 还可跟随球动作：

```json
{"type":"ball","event":"ball-id","phase":"end"}
```

动作删了，关联项保持待修复；不重新猜绑定。相同秒数的停点分别保留各自说明／图层。查看倍速不改变时间关系。

## 来源和兼容

内置内容复制建立独立身份，保留完整参考快照、曲线、分支、停顿、朝向、图层、文字和来源。原来的固定秒数不猜成动作依赖或共同链。防守重绘为五名防守者和命名目标；其码数为教学设置。其他规范化原图也映射到球场并明确教学距离；原数据仍可对照。

自编可没有链接；改编须保留至少一个具体原始链接。保留来源不表示修改后的整套战术由原作者支持。未有编辑控件的属性保留，不通过重建对象暗删。

文本改动或相关几何变化后，旧文及译文保留为待核对。教学只显示已确认文字，缺译文回退并提示；无可用说明则待补。统一说明随整套／球员／区域／职责／目标／停点选择。
