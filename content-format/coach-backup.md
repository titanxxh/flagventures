# 简洁画板编辑备份 v3

网页画板导入／导出 JSON：`format: "flagventures.backup"`、`version: 3`。它不依赖 PDF，不支持 v2 备份或内置内容使用的 v1 YAML／战术包。

[JSON Schema](coach-backup.schema.json)检查结构；已保存教学版还须通过五人、几何、球权、会合、停点及各类型最低内容校验。未命名、缺路线／说明或球路待调整的草稿可以保留。

## 战术库记录

| 字段 | 内容 |
| --- | --- |
| `records[]` | 单套或全库的战术记录 |
| `id`、`revision`、`updatedAt` | 身份、写入修订与更新时间 |
| `draft` | 自动保留的当前编辑草稿 |
| `saved` | 最近一次手动保存的教学版，可为 `null` |

没有保存版本历史。在线／固定来源本地服务使用原子事务和修订冲突检查；双击 HTML 使用临时会话，须导出备份带走内容。不同浏览器、网址和端口独立保存。新版首次升级会清空旧教练战术库，不迁移旧数据。

相同内容跳过，冲突逐条选择替换／复制／跳过。替换经确认覆盖这一记录的草稿和保存版；复制建立新身份并调整名称。导入不删除其他战术。未知格式、损坏结构或无法演示的保存版拒绝，读取失败不重置库。导入上限 25 MB。

## 编辑数据

每份 `play` 使用 `format: "flagventures.play"`、`version: 3`。

| 字段 | 含义 |
| --- | --- |
| `type` | `offense` / `run` / `route` / `formation` / `defense` |
| `title.zh/en` | 可先填写一种语言；正式保存须有唯一名称 |
| `field` | 30 × 70 码球场、开球线、端区和进攻方向 |
| `players[]` | 五人的身份、显示名称、站位、跑法术语、说明和共同跑位 |
| `scenarios[]` | 互斥球路选择；各自保存完整的球动作，不设共用动作链编辑 |
| `defaultScenario` | 最近保存选用的结局 |
| `initialOwner` | 初始持球人；普通进攻自动包含 C → QB 开球 |
| `bookmarks[]` | 点路线／场上创建的讲解停点、说明及可选防守图层 |
| `zones[]` / `assignments[]` / `targets[]` | 覆盖区域、静态职责、命名对方目标 |
| `origin` | 自编／改编声明、出处链接、完整参考快照与可能省略的旧结局数量 |
| `explanation` | 对象的中英文文字；编辑直接生效，不设确认按钮 |

路线支持直线、曲线和模板中的停顿。手绘整理成可播放的线段；通常按默认教学速度同时启动，安排交递时自动在几何会合处加入等待。球员菜单中的传球默认接在接球人路线终点；长按路线的「从这里传球」采用指定出手位置与 0.65 秒教学飞行时间，接球人按原路线移动。假动作不转移球权。没有实际交点的交递不能保存为完整教学版。

`motion.start`、动作秒数和球动作 `start` / `end` 由应用计算，界面不提供自定义先后、逐段耗时、数字坐标或单方案路线编辑。`sharedEvents` 在新画板中为空。`overrides` 仅作为自动会合等待的计算结果，保持共同路线形状；它不是教练可编辑的独立跑位。

## 路线上指定出手位置

传球事件可额外保存 `release`，例如：

```json
{"player":"Z","progress":0.6,"actions":["action-first","action-turn","action-last"]}
```

`progress` 表示原跑动路线的距离比例；`actions` 保存当时路线段的身份。应用将此位置转换成 Z 实际到达的时间，包括交递等待，然后重新计算 `start` / `end`。整体移动、节奏变化保留绑定；重画或清除路线后，需要重新选择出手位置，原传球不被静默丢弃。备份包含这些关系，仍使用 v3，无需清空已有战术库。

菱形表示出手位置；编号圆点是独立的讲解停点。多个传球选择保留各自完整的前序开球与交递。指定位置的传球检查持球先后、出手前是否持球过线，以及是否已有向前传球；无效动作不能保存为教学版。依据 [NFL FLAG 官方规则书](https://cdn.mediavalet.com/usca/rcx/DgBtnnoMFUCXWCBQE3YN2w/XMiAtpBTH0er4fUrKeYJAQ/Original/NFL_Flag_Rulebook_21423.pdf) 的 Running / Passing。

## 路线讲解停点

```json
{"type":"route","player":"X","progress":0.5}
```

`progress` 是沿整条路线的距离比例，范围 0–1，不是固定秒数。改变路线耗时、加入自动等待或整体移动后，停点仍跟随对应位置。重画路线会明确移除该人的旧停点，撤销可一并恢复。

球动作停点可绑定动作 ID；固定分镜可使用时间绑定及 `marker` 场上位置。静态防守可以有同一时刻的多个分镜，各自保存区域／职责显隐，不累积上一个分镜的图层。

## 来源与复制

内置教学页不被编辑修改。复制采用默认五人跑位，保留链接和完整原始快照，动画改为自动教学节奏。要求不同路线才能执行的旧结局不会进入简洁副本，并明确提示。旧说明里的具体动画秒数句略去；原始内容仍在内置教学页和参考快照中。

自编可以无链接；改编须保留原始出处。保留链接不表示新组合由原作者背书。新写文字直接用于教学；另一语言旧译文可保留待更新，缺少适用译文时回退并提示。所有导出都使用同一种 v3 编辑备份。
